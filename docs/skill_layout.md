Atue como um UI/UX Designer sênior. Preciso refatorar o visual/layout dos cards das telas de Login e Cadastro já existentes em um aplicativo mobile, adaptando-os para um fluxo baseado em validação por QR Code e dados simples.

[DIRETRIZES GERAIS DE DESIGN]
- Manter o fundo com a imagem da cidade e o efeito de transparência/desfoque existente.
- Manter o card branco centralizado, com cantos bem arredondados (border-radius elevado) e sombra suave.
- Manter o logotipo circular no topo superior do card, sobrepondo a borda superior.
- Usar a cor azul vibrante principal para os botões de ação primários (ex: #2563EB ou similar).
- Design limpo, moderno e focado em acessibilidade e facilidade de leitura.

[TELA 1: CARD DE LOGIN (QR Code)]
Objetivo: Permitir que o usuário faça login utilizando seu nome/telefone e/ou lendo um QR Code de validação.
Campos e elementos do card:
1. Título do card: "Entrar na Conta"
2. Campo de entrada 1: "Nome completo" (com placeholder simples ou underline).
3. Campo de entrada 2: "Telefone" (com suporte a máscara ex: (00) 00000-0000).
4. Botão de Ação Primária: "Entrar" (Botão azul preenchido).
5. Seção de Leitura de QR Code:
   - Divisor visual com texto "ou entre com QR Code".
   - Ícone/Botão de destaque com ícone de QR Code e o texto "Escanear QR Code para Login".
6. Rodapé do Card:
   - Link de navegação: "Não tem conta? Cadastre-se"

[TELA 2: CARD DE CADASTRO (QR Code)]
Objetivo: Cadastro simplificado solicitando apenas os dados fundamentais e gerando/validando via QR Code.
Campos e elementos do card:
1. Título do card: "Criar Conta"
2. Campo de entrada 1: "Nome completo"
3. Campo de entrada 2: "Telefone com DDD"
4. Botão de Ação Primária: "Cadastrar e Gerar QR Code" (Botão azul preenchido).
5. Seção informativa/QR Code:
   - Área centralizada para exibição do QR Code gerado para validação ou instruções de leitura.
6. Rodapé do Card:
   - Link de navegação: "Já possui uma conta? Entrar"

Gere o layout atualizado destas duas telas mantendo a proporção mobile e o mesmo padrão visual e estrutural apresentado na imagem de referência, ajustando apenas os componentes e textos especificados acima.
